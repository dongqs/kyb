- 02 growing-pains — 第二天：派活、CI 围攻、Runtime 觉醒
- 03 night-watch — 第一夜：12 容器无人值守
- 04 the-overhaul — 第三天：15 路体检、Boss 重生
- 05 the-big-experiment — 第二夜：130+ agent 七阶段实验
- 06 stabilization — 第四天：消灭波动源、稳定交接

**moments/** — 洞见时刻：起飞、上下文成本、Agent 社会学、退休、零信任。
