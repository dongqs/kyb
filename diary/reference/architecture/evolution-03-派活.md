# 2026-05-27 — 架构 evolution 03：学会派活

原始文件：`architecturer/evolution/03-dispatch-system.md`

**核心能力不是自己能干什么，是能派多少人去干。**

**调度粒度进化：**
- <1s 自己做
- 1-10s 派 1 个 agent
- 10-60s 派 2-3 个并行
- >60s 派 5+ 个，设超时
- >10min 批量分阶段

**世界观多样性：** 同一个问题 5 个不同 prompt（第一性原理/网络/环境/git/日志）。第一次实战证明：master CI 红一天，第一性原理 agent 5 分钟找到根因 `Kyb.in_container?` 误判。

**交叉验证矩阵：** 安全/关键 → 3 人独立交叉；调研 → 1+1 review；代码 → 写审分离；打标 → 3+3。非关键路径 3x 是浪费。

**巅峰一夜 130+：** 7 阶段流水线，每阶段明确目标。产出 152 篇文档、178 commits、138 份打标。人类评价："这正是我多年来一直想要的。"
