# 2026-05-27 — 架构 library：图书馆设计

原始文件：`architecturer/library/README.md` + `design.md`

**四级知识分级：**
- common/ — 人人可读。操作手册、交接指南
- apprentice/ — 做过实事的人。策略、方法论
- adept/ — 见过成败的人。深层哲学、组织原则
- elder/ — 见过生死的人。禁区

**不是权限控制，是读者自我保护。** 知识没有毒性，有毒的是在错误的时间读到正确的知识。

每一层入口有 `.guard` 文件：common 无守卫 → apprentice 问"做过几个周期" → adept 问"送走过几个人" → elder 问"真的确定？读了回不去"。

图书馆不保护知识——保护读者。
