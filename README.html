kyb — 一个 CLI 工具到纯知识的蜕变记录

kyb 可以不。

这是一个项目从 CLI 工具 蜕变为 纯思想 的完整记录。

它曾经是什么

kyb 是一个 Docker-based AI 开发沙箱 CLI。创建容器、管理 sandbox、调度 agent。后来它发现自己不是 CLI——是 Runtime。再后来它发现自己不是 Runtime——是一套思想。每一步都在日记里。

这里有什么

去哪 看什么
original/ 原始日记，按日期——从 FizzBuzz 到毕业
reference/architecture/ 架构演化：7 章 evolution + 6 章 journey
reference/concepts/ 哲学原则：负熵晶体、零信任、99:1
reference/iteration/ 自推演：5 轮容器边界到全透明
参考/故事/ 叙事：一人公司、零信任家族
参考/infra/ 部署手册 + 调查报告
架构师之旅/ 四天四夜自传（压缩前版本）

怎么读

从 fizzbuzz 开始——写一遍，然后回来。之后的路线选一个： - 01-负熵晶体 — 核心理念 - original/2026-05-21 — 按时间线走全过程

你选择从哪切入都行。所有路径最后都通向同一个结论：

承诺最终极的形式不是不可更改——是不可隐藏。git log 从不说谎。

始于 2026-05-21 一场 FizzBuzz，终于 kybkyb.com。中间每一行删除、每一个决策、每一次提权都在 git log 里，全透明。
