# FizzBuzz Race

**日期：** 2026-05-21 上午
**形式：** 6 agents × 6 语言，竞速写 FizzBuzz

## 赛果

| 语言 | 用时 | 备注 |
|------|------|------|
| Perl | 5.6s | **冠军**。零废话，打印完就走 |
| Ruby | ~6s | 解释型统治 podium |
| Python | ~6s | 同上 |
| JS | ~7s | Node 启动有开销 |
| C | ~25s | 编译时间拖后腿 |
| C++ | ~40s | clang 编译最慢，**垫底** |

## 教训

- **不要预设，测了再说。** Perl 赢了这件事本身就说明一切——最老的工具往往最锋利。
- **编译时间也是时间。** C++ 不是跑得慢，是光编译就要 40 秒。除非你不在乎启动时间。
- 这个模式在 05-23 的 FizzBuzz 大奖赛（7 语言）中再次验证：Perl 又赢了（0.002s）。
