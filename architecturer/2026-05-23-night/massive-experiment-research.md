# Phase 4: 百人全面调研

**时间：** 00:30-02:00
**规模：** ~100 agents，每方向 3 人交叉
**产出：** ~120 份调研文档（最终 127 份）

## 覆盖方向

桥梁 / MCP / 巡检 / 告警 / 成本 / 安全 / 拦截 / 存储 等全方向

## 评价：实验的核心阶段

**值得吗？** 是的，但不完全。

### 正面

138 份文档一夜产出。正常一个人写一份深度调研要 2-4 小时（读代码、查文档、推理），138 份 = 276-552 人时 = 34-69 人天。就算打 5 折也是 17-34 人天。一夜搞定，时间压缩比 ~50-100x。

### 浪费

1. **同质化交叉** — 3 个 agent 查同一方向，80% 结论一致。非关键路径的 2 倍 token 是浪费的。
2. **格式不统一** — 前期缺少输出模板，后期汇总费力。
3. **上下文过载** — 同时跟踪 100 个 agent 状态增加认知负荷。

### 优化建议

- 关键路径（安全/决策）：3 人交叉
- 非关键路径（调研/信息收集）：1 人 + 快速 review
- 分批派工：20-30 一批，不是 100 一搏
