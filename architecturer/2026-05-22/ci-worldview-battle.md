# CI 5 世界观 Battle

**日期：** 2026-05-22
**问题：** master CI 红了一整天，原因不明，日志无头绪

## 策略

不开一个 agent 查。**开五个。** 五个不同世界观的 agent 同时从不同角度进攻：

1. **第一性原理 agent** — 从最底层前提推导，假设所有上层理解都是错的
2. **网络 agent** — 假设是网络/代理问题
3. **环境 agent** — 假设是 Docker/CI 环境差异
4. **git agent** — 假设是 merge 冲突或历史问题
5. **日志 agent** — 假设日志里有答案只是没看对

## 发现

第一性原理 agent 最先到达终点。根因：`Kyb.in_container?` 方法在 CI 环境中误判了——它检测到 `/proc/1/cgroup` 有 Docker 痕迹就返回 `true`，然后触发了 kill 进程的逻辑。测试跑着跑着就被自己杀了。

修复：加上更严格的判断条件，区分测试环境和真正的 kyb 容器。

## 意义

五个 agent 同时攻击的策略赢了。如果一个个试，可能还在第三个假设上打转。
