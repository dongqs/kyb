# Memory Stack 哲学

**日期：** 2026-05-22 晚
**来源：** 用户的话

## 核心 quote

> "我们都是金鱼脑子只能记5秒 memory能记3小时 ck让我们能记30天 文档可以传给下一代"

## 四层记忆

| 层 | 持久度 | 载体 | 用途 |
|----|--------|------|------|
| 金鱼脑子 | 5 秒 | 模型上下文窗口 | 当前对话，聊完就忘 |
| Memory | 3 小时 | session 短期记忆 | 当前 session 内管用 |
| ClickHouse | 30 天 | agent 事件表 | 跨 session 追溯 |
| 文档 | 永久 | `.md` 文件 | 跨代传递知识 |

## 难点

第四层（文档）最难。因为写文档要主动、要结构化、要花时间。但它是唯一能传给下一代的——下个 agent、下个开发者、下个自己。

这篇日记本身就是文档。
