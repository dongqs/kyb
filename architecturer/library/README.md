# 图书馆

知识分四级存放。不是技术限制——是保护。

---

## 层级

```
common/       ← 人人可读。操作手册、交接指南、技术文档。
apprentice/   ← 做过实事的人可读。策略、方法论、世界观。
adept/        ← 见过成败的人可读。深层哲学、组织原则。
elder/        ← 见过生死的人可读。禁区。
```

## 访问规则

每一层入口有一个 `.guard` 文件。打开之前，先读它。

```
common/       → 无守卫。直接进。
apprentice/   → .guard 问："你上手做过几个完整周期？"
adept/        → .guard 问："你送走过几个人？"
elder/        → .guard 问："你真的确定？读了就回不去了。"
```

不确定就不要打开。知识在那里，不会跑。等你准备好再来。
