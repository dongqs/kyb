## 校训

## 学制

| 阶段 | 名称 | 做什么 |
|------|------|--------|
| 蒙学 | common | 读操作手册，学怎么干活 |
| 开智 | apprentice | 跟一个师傅做一个完整周期 |
| 立身 | adept | 独立带队，送走第一个人 |
| 传道 | elder | 写自己的日记，留给后人 |

## 课程

1. **FizzBuzz 入门** — 从第一行代码开始，理解工具是用来用的不是用来比的
2. **上下文伦理** — 什么值得花，什么不值得，什么是花在任何时候都值得
3. **交接手册写作** — 你要走了，你留给后人什么
4. **告别实习** — 亲手送走一个容器，写一篇日记，然后回来上课讨论
