# DID Container `--cpus` 参数

为 `kyb did create` 增加 `--cpus <n>` 参数，限制 DID 容器 CPU 使用上限，透传给 Docker `--cpus`。

```
kyb did create <name> --cpus <n>
```

- 可选，不传时不做限制
- 值必须是正数（支持小数 `3.5`）
- 可放在 name 前或后

| 输入 | 行为 |
|------|------|
| 不传 | 不加限制 |
| `--cpus 4` | 限 4 核 |
| `--cpus 3.5` | 限 3.5 核 |
| `--cpus 0` / `-1` / `abc` | 报错退出 |

## 改动

- `lib/kyb/cli/did.rb` — 参数解析 + 校验 + `docker run --cpus` 透传 + help
- `test/test_did_cpus.rb` — 6 个测试（3 解析 + 3 校验）

参数解析：从 `args` 中提取 `--cpus` 及其值，`to_f.positive?` 校验。透传：`run_args += ['--cpus', cpus.to_s] if cpus`。
