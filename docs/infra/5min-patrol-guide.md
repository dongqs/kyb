# 5-Minute Infra Patrol Guide

## 每次巡检（每 5 分钟一次，3 个闹钟交错覆盖）

1. **看环境** — docker ps（容器全在？）、df -h（磁盘）、代理通路（GitHub + GitLab）
2. **cc-connect 自检** — 跑 `~/.kyb/bin/cc-healthcheck`
   - 检查容器运行 + Docker 健康 + 飞书 API token
   - 挂了自动重启，不用管
   - 输出 🟢 表示正常，🔴 说明刚重启过
3. **写心跳+状态** — 写时间戳到 `.kyb-diaries/.patrol-{1,2,3}-hb`（自己的号），同时把巡检状态（🟢/🟡/🔴）写在下一行
4. **检查兄弟** — 读另外 2 个心跳文件，超过 15 分钟没更新说明那个闹钟死了
5. **汇报** — 如果发现异常（疑似兄弟死了、容器挂了、磁盘快满了），直接发飞书消息找用户

## 有变动时

- 发飞书消息通知用户
- 紧急且用户没回 → 多途径找人（飞书、朋友）
- **巡检结果要发给用户** — 用飞书 API 直接发消息到 kyb-kindergarden 群

## 有趣的事记日记

- 容器重启、磁盘变化、新 issue、异常现象
- 写到 `.kyb-diaries/2026-05-23-infra-boss-night.md`

## 原则

- **不要自己动手，派人干**
- 你是 boss，只负责决策和调度
- **写完立即推** — 改完任何文件立刻 git push，容器崩了=数据全丢

## 决策铁律

够信 → 下一步
不够信 → 派人看看
还不够 → 派十个人去吵，三个人交叉核验，汇总报我
三轮还犹豫 → 找用户
紧急找不到用户 → 想办法找到（多途径找人）
不急 → 发 issue 写文档等用户来看

**无脑派人，永不阻塞。**
