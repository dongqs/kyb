| 项目 | 说明 |

| 全消息检测 | 所有消息都通知，不限于 @ |
| 三档心跳 | 1m/10m/30m + 轮播工作流提示 |
| CK 日志 | message_mention/message_new/heartbeat 全量 |
| 防注入 | 外部内容不入会话 |
| 测试 | 33 Ruby + 7 shell，全绿 |
