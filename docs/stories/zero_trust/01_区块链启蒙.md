# 区块链启蒙

## 信任原理

区块链将信任从「相信人/机构」转移到「相信代码和数学」。核心机制：

- **分布式账本** — 每个参与者有完整账本副本，单点篡改即被全网拒绝
- **哈希链** — 区块间通过前一个区块的哈希串联，修改一个区块会破坏整条链
- **共识机制** — 修改历史需要 51% 算力，成本高到不现实
- **数字签名** — 私钥签名交易，公钥验签，不可伪造、不可抵赖

## 数字签名与身份

在区块链中，「私钥即身份」——拥有私钥就被系统认定为账户主人。不存在找回密码或申诉机制。

## 哈希时间证明

要证明某个哈希值在特定时间之前就已存在：将其写入一笔交易的 `OP_RETURN` 输出 → 被打包进区块 → 区块时间戳锁定存在时间。工具如 OpenTimestamps 可自动化这个过程。

哈希值本身不携带时间信息，必须依赖外部不可变的时间记录。

## 比特币分裂

核心矛盾：大区块派（链上扩容，坚持「点对点电子现金」）vs 小区块派（二层扩容，走「数字黄金」）。主要分叉：

- **BCH**（2017）— 从 BTC 硬分叉，区块上限提至 8MB
- **BSV**（2018）— 从 BCH 再分叉，追求极端扩容

## 如何避免分裂（如果再来一次）

1. **治理**：加权投票 + 仲裁委员会 + 僵局冷却期
2. **技术**：优先软分叉 + 分阶段激活 + 兼容层
3. **沟通**：公开争议会议 + 第三方审计 + 实验性分叉链先行验证
4. **宪法规则**：设定不可随意修改的核心契约，硬分叉需同时满足多方超多数门槛

分裂不一定全是坏事——它倒逼不同路线各自验证，但也代表治理失灵。
