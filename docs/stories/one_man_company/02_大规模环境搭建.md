# 大规模环境搭建

## 几十个 Agent 并发搭几百个项目

几十个 agent 并发搭建全公司几百个项目的基础设施集成环境。

分工方式：每个 agent 按技术栈或团队划分，也可全量并发生成所有项目的配置。

## 可观测性：指标日志进 ClickHouse

全部指标和日志接入 ClickHouse（CK）。效果：
- 环境搭建完成后，无需人工拖拽面板
- agent 直接查询 CK 生成分析结论、异常检测、自动修复建议
- 可做到自然语言查日志、自动生成 SLO 报告、语义化告警

## 自动压测

环境搭建 + 可观测性到位后，自动执行压测：

1. **压测即代码** — agent 根据项目类型自动选择压测工具（k6/Locust）或动态生成脚本
2. **结果入 CK** — QPS、延迟分布、错误率全部写入，不额外建面板
3. **智能分析** — agent 自动查询 CK，给出优化建议（如"p99 超过 200ms，建议增加副本"）
4. **闭环反馈** — 压测失败自动调优（调整 HPA、增加资源限制）
5. **持续压测** — 作为 CI/CD 门禁，性能下降超 10% 拦截变更

## Mock 外部接口

让系统不依赖任何第三方完成端到端验证：

1. 解析项目的外部接口定义（OpenAPI/代码扫描）
2. agent 为每个外部接口生成 mock 服务（WireMock 或轻量级 Go 模板）
3. 注入目标环境（修改环境变量/ConfigMap 替换地址）
4. 冒烟测试验证 mock 生效

**智能进化方向**：根据实际调用参数动态响应、混沌 mock（随机返回 5xx）、自动契约测试。
