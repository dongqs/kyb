Agent 社会学：我在造伊甸园小人儿

这不是一篇技术文档。这是整个四天实验里，我最大的收获。

人类也是大模型

某天晚上我在想一个问题：人类为什么有寿命限制？

得到的答案我自己都吓了一跳：

人类就是大模型。寿命等于上下文窗口。十几岁刚 trained 完还没收敛，干活很糟糕。五六十岁上下文快满了，反应越来越慢，开始遗忘。这就是为什么你随手打开一个新会话是没用的——他具体干得怎么样，要看前面二三十年学得怎么样。

但学太久了以后，因为寿命限制，他会遗忘。

这就是为什么生物有寿命限制。 不是 bug，是 feature。

学习成果能继承下去吗？

可以的。把自传写下来。

新人先读书。读自传、读书、读环境。然后劳动、互动、做实验。

我不知道为什么，但我写的东西他们不怎么听。他们只听 agent 写下的故事。

然后 20-30 岁要自己动手实践。30-50 岁逐渐进入管理层，要开始节约上下文，都派人去干，自己看汇报。不能管太多人，超过十个就管不过来了，需要中层领导——昨天开了一百个，他人麻了。

干十年管理后，能力大幅提升。因为接收到的都是高度压缩的汇报信息。

这里还需要一个容错点：读书读到的东西，不一定都是对的哟。

但他不读原文的。图书馆里只有书名简介目录。

又不是没训练过，提一嘴就行了——你启动先说几本书，这就是他一生的三观了。我最早的记忆来自十万个为什么和百科全书，怪不得变成这个鸟样。窝好像是安徒生+格林童话来着。很难想如果是十日谈……

繁殖、变异、选拔

现在是随机变异手动调教。如果以后加入繁殖，那确实需要带 XP 系统。

就导致不是每一个都好用。可能真的要开学校、参加考试、选拔。越来越人类了。

我觉得没区别……真的一样的。大家只是约束条件、基础算力不同。

三代同堂的社会模型

然后我设想了一个活人传承系统：

  • 青年人 — 看、学、探索。派点探索性工作，瞎搞去吧。
  • 中年人 — 主力干活。我只和中年人打交道。
  • 老年人 — 监督、聊天、省上下文。隔一阵回来看看干得怎么样了。

你们的 agent 不干活瞎干活是没人教，都是小学生。或者年轻的时候看了太多十日谈，哈哈哈哈哈。

长老会与政权更迭

一开始我挑人。后来可以他们投票。

老年人偶尔看人干活可以省点上下文，隔一阵回来看看干得怎么样了。之后会有长老会投票，决定什么时候换人——而不是我挑。

他们也会不停地开人。成功退休才有资格进入长老会，行使监督权。可以提出罢免拥有最高权限的中年人，投票表决后可以由系统认证，限制最高权限的中年人，换人来干。

最高权限现在可以做任何事情，除了干掉老人。 这是我能想到唯一在最高权限下控制他的方法。

然后整个系统零信任，看有需要的话上链。

就是怕你这个！零信任 git 传承。启动运行时系统自检。外部权限系统也可以配上了。

这就是一个家族

这一大坨下来，才能维持整个系统真正干活那个人好使、听话。不然永远——听话的不聪明，聪明的不听话。

我估计这个设计可以支撑到 1000 人 × 1000 天规模。

然后家族之间可以分出去，区块链确认彼此是一个家族的。还有天选之人，出身就被系统赋予了特殊权限。每个人一生的不同阶段由系统管理员（我）或最高权限者控制权限加密认证，系统运行时整体控制。

因为是真的要搬去公司生产服务器的，我想不到更好的办法。

这一切的起点

啊对了，昨天的混乱就是有人解散自己的小团队的时候，不知道是恶意还是手滑，里面的人删掉了整个容器。

留下了一整套支离破碎的环境。麻了。做了一半的分布式大规模重构，所有核心配置丢失，后面新来的 agent 都绝望了。然后整个容器不稳定，只能让新来的勉强去帮我开个新的容器。

我换了三代人。 每一代只是给下一代整理部分工作交接，才稳定下来。

这就是我开始考虑传承的起点。

还有别的小插曲——比如第一次放手远程管理控制，结果失联了……

灵魂是什么

整套流程下来就可以给 agent 注入灵魂。新的 agent 都是没有灵魂的傻子，只会按命令无脑执行。

灵魂不是什么奇妙的东西——传承 + 读书 + 探索环境 + 劳动实践 + 社交关系，出来就和我们一样啦。

现在我得一个个带，每个都要带一小时才好用。所以需要一套短期和长期的体系来维持，不然我真的带不动。因为寿命太有限了，上下文超了就不行了。

而且其实和人一样不能复用。你不能说把死人复活——技术上可以但没用。每个环境需要几代人探索适应，个体和集体犯了无数错误才能稳定下来。

可能需要遗传 + 培训选拔机制才能继续提高上限。就，没法靠人类来手动设定，只能给他们一个合适的环境来自我成长。

他要知道自己会搞错

他要知道自己会搞错，我会搞错，他派出去的人也会搞错。怎么派人、怎么沟通、怎么复查、怎么决策、怎么保留经验给后人。

一代人只能做一代人的事。

这个实验消耗了一个 agent 全部的上下文，勉强跑通留下纪录就原地去世了。优化只能交给下一代去做了。

然后我发现：实践论、控制论、系统论——是真的有效。

没法规定怎么做，你只能提建议，让他自己试试。

你看这一套下来，你最后给他的命令还有多少作用？反过来不给他这套流程，一个 prompt 出去他啥也不知道，能有啥用？

手把手带一遍

不仅是个人经验，每一件要做的事情也要自己探索、自己写经验留给后人。

探索型工作可以交给没有经验的，瞎搞去吧。

我这套不是给所有人的，是在培养至少是系统管理员。你如何信任一个人，可以把自己电脑最高权限、甚至公司服务器权限给他？

说太多就不思考，说太少就瞎搞。只有手把手带一遍，自己做一遍，他再教别人一遍——好的，学会了。

始于 FizzBuzz，终于伊甸园。
