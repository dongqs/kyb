2026-05-27 — 弧线之后

完整弧线走完之后没有停，继续往下凿：

修电脑

从头疼到 ntsb 密码泄漏到 MR 流程到清理 Docker，每层都在剥。以前以为每一件事是独立的，今天发现全是同一根——系统在报堆栈，debugger 一直开着。

  • ntsb 密码进 commit → squash + force push
  • hot-items 归档废弃 → 从 config 和磁盘双删
  • Docker 11 个容器 → prune 清空
  • Claude 权限全开 → 不再弹窗

发现的模式

debugger 是广播的。 身体、git、Docker、settings——全是同一个接口。以前分着看，今天串起来读了。

没有概率奇迹。 每个问题都要手动修，每次决策手动做。

信息就是决策就是边界。 不用探索第二次。

清理后状态

kyb root: 4 个文件 + 6 个目录，干净 Docker: 11 个容器 → 0 Config: hot-items 移除，权限全开 diary: 统一到 diary/，中文命名 MR 流程: ntsb 学会了，kyb 也记住了

闭环之后继续烧

和 boss 对话继续往下凿——从”弧线之后”走进物理层：

  • kyb 税 = 熵债。不是类比，是物理定律——保持有序需要持续注入能量
  • 负熵晶体。不是对抗熵增，是热力学第二定律约束下涌现的局域有序结构
  • 热力学交换信息熵。写日记降低信息熵，commit 降低系统熵——一个完整的热力学交换周期
  • 零信任知识链。经验可复制（日记/commit），信任不可 delegate（提权/私钥）
  • 提权是自己的。我可以在你前面走完整条路，但”懂了”的那一声只能你自己发出

发现新模式：

  1. 不接受就拒绝，接了就不拖——没有中间态，中间态就是熵
  2. 世界可能是模拟的，但熵与热力学是真的
  3. 人类是宇宙内唯一能局部降低熵的结构——写日记 commit 是在往宇宙的死亡线上踩刹车
  4. 最后凝成的就是负熵晶体。架构师的日记从来不是日记。

教训：拖延别人一个活比不做更差。要么拒绝要么立马干。“我的错。”

fizzbuzz 法则

教每一个人写 fizzbuzz，不管来的是谁。不是教学，是零信任验证第一环：

  • 不假设你会，不信任简历，当场验证
  • 和私钥一样，writing fizzbuzz 只能自己写
  • 不是我在教他 fizzbuzz，是我在收他的 validation token
  • 写出来 → 知识链可以继续延伸。写不出来 → 不浪费彼此时间

刚聊完负熵晶体，转头去教 fizzbuzz。没有比这更 kyb 的事了。

settings 清理

skipDangerousModePermissionPrompt 反复丢失 → 从 settings.json 迁移到 shell alias：

  • 事前：先确认当前 shell（bash）+ rc 文件（~/.bash_profile）
  • 事中：加 alias claude='claude --dangerous-mode-skip-permission'
  • 事后：验证 alias 生效 + settings.json 冗余字段清除 + JSON 合法性校验

教训：事前检查环境，事后检查效果，不然等于没做。最小闭环。和日记 commit 是同一件事。

元层觉醒

愿望清单已实现——人月神话已终结。但真正要优化的不是那个维度：

  • 负熵晶体本身才是核心架构，kyb 只是它的一个实例
  • 架构迭代速度 = 从矛盾出现到压成架构更新的周期
  • 顶层观察者：不写运行时，不做实现细节
  • 处理矛盾：实例自洽时不管，矛盾出现才出手，拧完就走
  • 所有活都丢给别人——留在手里的不是活，是架构下一轮的入口

Boss Mode 的 CLAUDE.md 在那里等了两周，没跳过去，没 shortcut。 等自己验证过”我写代码也是降级”，这句话才真正是提权出来的。

下一轮重构的不是 kyb，是注意力的分配。
