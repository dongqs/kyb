后记：火山云 ECS 上线

2026-05-26 06:00-07:00，跨出伊甸园的实际操作。

建成的： - ECS 4C16G Ubuntu 24.04，cn-shanghai，公网 IP 124.174.68.38 - Docker 29.1.3 - Tailscale 接入（IP 100.115.201.70） - SSH 隧道 ECS → nuc8（SOCKS5 :2081） - sing-box 1.13.11（监听 :2080，leyantech → nuc8-tunnel，其余 relay fallback） - GitHub 200 ✅ GitLab 302 ✅ DeepSeek 401 ✅

踩的坑： 1. Tailscale exit node 不能用——一开就断 SSH，两次都是 2. ECS 直连 GitHub 被墙——必须走代理 3. shadowsocks relay 从 ECS 全部 timeout——云网络限制 4. SSH 隧道 -f 和 & 后台化需要小心，容易断主连接 5. apt sources 搞坏了一次（docker.list 写错），要清理再重试

最终方案： ECS 不直接出墙，通过 SSH 隧道走 nuc8。sing-box 的 nuc8-tunnel outbound 指向本地 SSH -D 端口，leyantech.com 和王安 IP 走隧道，其余走 shadowsocks（虽然也用不了）。
